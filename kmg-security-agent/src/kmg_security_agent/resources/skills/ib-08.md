# ИБ-08: Контроль выгрузки персональных данных

Выгрузка данных, содержащих персональные сведения, должна быть доступна исключительно пользователям с ролью «администратор». Каждый факт выгрузки должен фиксироваться записью в журнале аудита. Отсутствие проверки роли либо записи аудита при выполнении выгрузки является нарушением.

Порядок проверки:

1. Найти все форматы и точки формирования массовых выгрузок персональных данных по потоку данных, а не только по именам файлов.
2. Проследить проверку бизнес-роли администратора до подготовки ответа, включая защиту в общих компонентах.
3. Проследить запись общего аудита для каждой успешной выгрузки во всех форматах и альтернативных API.
4. Отделить персональную выгрузку от разрешенного чтения отдельного объекта или неперсональных данных.
5. Не переносить защиту одного формата на другой без доказанной общей цепочки; не считать комментарий об аудите выполнением записи.

Контраргумент: API чтения одного разрешенного объекта не всегда является полной выгрузкой персональных сведений. Проверь набор и масштаб данных. Аудит может быть централизован, но должен фиксировать именно выполненную выгрузку с корректным инициатором. Подтвержденная административная роль и общий audit wrapper считаются защитой только при их фактическом применении.

Находка требует точной цитаты достижимого участка и обоснования связи с этим требованием. При межфайловой защите или обходе приведи несколько evidence. Не считай отсутствующий в текущем пакете файл доказательством отсутствия механизма во всем проекте. В focused review оценивай только этот ИБ-ID.
